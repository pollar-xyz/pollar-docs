**Dashboard > Overview > Home** · Chains: all

The per-app landing page. From top to bottom:

- **API v1 banner**: shown while the app has called SDK API v1 in the last 30 days, with the retirement date, the last v1 request, the number of v1 requests and the times of any announced rehearsal windows. See [API versions](https://docs.pollar.xyz/docs/sdk-reference/api-versions).
- **Finish setting up your app**: shown until every step of [Get started](https://docs.pollar.xyz/docs/operator-guide/overview/get-started) is done, with a link to it.
- **Insights**: transaction metrics over the last 7, 14 or 30 days (selector on the right, plus **Refresh**):
  - one card per asset with its transactions today and over the range
  - **Transactions by asset**: daily transactions by token
  - **Distribution**: share of transactions by token
  - **Transaction count**: daily transactions

The metrics count transactions; they are not amounts. Each app has its own Home; switch apps from the top navigation bar.
